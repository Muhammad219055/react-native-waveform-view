# rn-waveform

A short alias for [`react-native-waveform-view`](https://www.npmjs.com/package/react-native-waveform-view).

```sh
npm install rn-waveform
```

```ts
import { Waveform, useWaveform } from 'rn-waveform';
```

Both names install the same library. Documentation lives in the main package.
